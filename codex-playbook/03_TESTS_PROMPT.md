# Tests Prompt

You are working in `/workspace/soul-canvas`.

Objective:
Add or update tests to cover the target behavior and reduce regression risk.

Allowed scope:
- existing test directories/files
- `src/**/*` only when necessary to make tests meaningful
- test/tooling config only if needed for test execution

Required checks:
- Run `npm run sanity` and report result.

Output format:
1. Summary
   - What behavior is now covered and why.
2. Changed files
   - List each test/code file changed with rationale.
3. Risks
   - Gaps not yet covered, flaky areas, or assumptions.
