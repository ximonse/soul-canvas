# Codex Playbook

This folder contains copy-paste prompts for common Codex workflows in this repository.

## How to use
1. Start with `01_BASELINE_PROMPT.md`.
2. Run the phase-specific prompt that matches your task.
3. Track progress in `STATUS.md`.

## Prompt contract
Each `*_PROMPT.md` includes:
- exact objective,
- allowed scope (which files),
- required checks (`npm run sanity`),
- output format (summary + changed files + risks).
